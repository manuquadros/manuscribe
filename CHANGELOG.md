## 0.2.0 — 2026-09-19

### Breaking

- Rename package pdfparser to manuscribe (`008af13`)

  The distribution, the import path, the exception base class
  (PdfParserError -> ManuscribeError) and the environment-variable prefix
  (PDFPARSER_* -> MANUSCRIBE_*) all change together. Old PDFPARSER_*
  variables are no longer read: a deployment that still sets them falls
  back to the built-in defaults without an error. The nested
  pdfparser-tickets/ backlog keeps its directory name.


### Added

- Parse chandra-ocr-2's div-tree response into Block directly (`bf30e2d`)
- Select the OCR response parser per OcrModel via an engine knob (`61da51c`)
- Infer the OCR engine from the weights the server reports (`68fdddc`)
- Resolve card- and model-dependent vLLM flags at start time (`87e5bcc`)
- Add an attention-backend benchmark (`a217c6e`)

### Fixed

- Attach a heading-form figure caption to its adjacent placeholder (`54806dd`)

### Internal

- Switch version from a static field to scm-derived tags (`9452316`)
- Require NGC 26.06+ and prefer vllm-openai v0.29.0 (`ead12fd`)
- Record why the text-layer hybrid was rejected (`f74c073`)
- Add CHANGELOG.md (`19281f9`)

## 0.1.0 — 2026-09-19

### Breaking

- Bind loopback by default (`7a2b5b1`)

  run-server.sh published on every interface, matching podman's default
  for a -p with no address. deploy/p100/shim.py has always defaulted to
  127.0.0.1, so the two deployment paths disagreed on the one setting
  that is the whole access control -- vLLM has no auth of its own.

  Both now default to loopback. Reaching the server from another machine
  is an explicit act: BIND_ADDR="$(tailscale ip -4)" ./run-server.sh.
